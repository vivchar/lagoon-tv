# Lagoon TV — правила для агентов

Свой лаунчер для Xiaomi TV Stick 4K (Android 11, 2 ГБ памяти, слабый CPU).
Чистая Java 17, без AndroidX, без библиотек, без XML-разметки: весь
интерфейс собран в коде. Подробности — в [docs/](docs/), начни с
[docs/architecture.md](docs/architecture.md).

## Сборка

```bash
./gradlew assembleDebug
```

Тестов в проекте нет. Правку проверяют на эмуляторе Android TV
(см. [docs/testing.md](docs/testing.md)) и смотрят скриншот.

## Правила

- **Никаких зависимостей.** Ни AndroidX, ни Gradle-библиотек. Нужна
  функция — пиши сам или бери из Android SDK (API 30).
- **Размеры только через `Ui.px(context, n)`**, где `n` — единицы макета
  1280×720. Никаких dp, `dimens.xml`, сырых пикселей.
- **Цвета, шрифт и контролы — из `Ui`.** Новый цвет или компонент сначала
  добавь в `Ui` и в [docs/design-system.md](docs/design-system.md).
- **Каждый новый фокусируемый элемент** проверь с пульта: куда ведут
  стрелки, что делает Back, виден ли фокус (`Ui.focusable` / `Ui.grow`).
- **Главный поток не блокировать.** Сеть, файлы, декодирование картинок —
  в фоновом потоке, результат на главный через `Handler`.
- **Картинки декодировать с `inSampleSize`** под размер на экране. Полный
  размер на стике съедает десятки мегабайт.
- **Строки интерфейса — только в `res/values*/strings.xml`**, не в Java.
  Русский — язык по умолчанию (`values/`), остальные пять лежат в
  `values-en`, `values-th`, `values-zh-rCN`, `values-es`, `values-de`.
  Каждая новая строка сразу во всех шести файлах; числа с подписью — через
  `<plurals>`, даты — через `Lang.date`. Комментарии в коде на английском,
  как в соседнем коде. Комментарий объясняет зачем, а не что.
- **Секреты не коммитить.** Токен бота, ссылки на альбом и календарь
  вводятся на телевизоре и живут только в его настройках. В коде, доках
  и скриншотах — только выдуманные данные.
- **Скриншоты для README** — только с эмулятора с моками
  (`tools/mock_data.py`), не со стика с настоящими сообщениями.

## Устройства

- Стик подключается по ADB через сеть. Не ставь на него сборку и не меняй
  настройки без просьбы: на нём смотрят ТВ.
- Эмулятор Android TV 1080p годится для всего, кроме кнопок Netflix и Prime
  Video на пульте (их видно только в logcat прошивки Xiaomi).
- Если подключено несколько устройств, всегда указывай `adb -s <serial>`.
