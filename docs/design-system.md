# Дизайн-система

Всё в `Ui.java`. Тёмное стекло поверх живой сцены, белый текст, шрифт Inter.
Размытия нет (на стике дорого), поэтому стекло — полупрозрачная заливка, а
диалоги почти непрозрачные.

## Размеры

Макет — 1280×720 единиц. В пиксели переводит только
`Ui.px(context, n)` = `round(n × ширина экрана / 1280)`. На 1080p единица ≈ 1,5 px.
Никаких dp и `dimens.xml`.

`Ui.font(c, weight)` кэширует гарнитуры, `Ui.text(c, s, size, weight, color)`
создаёт `TextView` без отступов шрифта.

| `Ui.toggle` | Ui | Синий, когда включено |

| `Ui.round` | Ui | Круглая системная кнопка с подписью |
| `Ui.icon` | Ui | Векторная иконка в цвет текста |

| `chip()` | MainActivity | Пилюля высотой 48 |
| `segmented()` | MainActivity | Пилюли в стеклянном жёлобе высотой 58 |

## Фокус и пульт

- Плитки дока: одна общая рамка `FocusRing` (белая 3 px), едет за фокусом,
  плитка увеличивается в 1,07 раза.
- Остальные контролы: `Ui.focusable` / `Ui.grow` — рост до 1,07 (у широких
  строк не больше 10 px на сторону), `translationZ` 6, 280 мс.
- Карточка заметки в фокусе становится белой с тёмным текстом.
- Родителям выросших элементов отключают обрезку (`unclip()`).
- Стрелки обрабатываются в `MainActivity.dispatchKeyEvent`:
  - док: ←/→ соседняя плитка, ↑ к заметкам или погоде, ↓ настройки;
  - погода: OK — экран погоды, → к заметкам;
  - заметки: OK — прочитано или играть медиа, ← к погоде, ↓ с последней — в док;
  - на странице Back — назад, ↑ с верхнего элемента закрывает настройки и погоду.
- Удержание OK на плитке дока — меню: закрепить, переместить, удалить.

## Тексты

Русский, прямо в Java. Кавычки «ёлочки», тире —, числа с подписью через
`plural()`. Подсказки управления внизу страницы: «↑ или Back — на главный».
